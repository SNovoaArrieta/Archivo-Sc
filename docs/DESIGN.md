# Archivo Secreto — dirección visual

## Objetivo

Crear una experiencia interactiva simple y estable para compartir pantalla durante una videollamada.

No es un videojuego. No debe tener controles de teclado, físicas, colisiones ni misiones.

## Estética

- expediente confidencial
- escritorio oscuro
- carpetas físicas
- documentos impresos
- sellos
- papel envejecido sutil
- iluminación cinematográfica
- detalles de oficina/investigación
- interfaz limpia y elegante

Evitar:

- apariencia de dashboard corporativo
- exceso de cajas genéricas
- emojis como recursos visuales
- animaciones llamativas
- mecánicas que puedan romperse

## Flujo

1. Portada del expediente.
2. Panel con cuatro carpetas.
3. Daiana elige el orden.
4. Cada carpeta abre un documento distinto.
5. Al revisar las cuatro se desbloquea el informe final.
6. Cierre nocturno y mensaje personal.

## Tono

Natural, divertido y cercano. No excesivamente romántico ni empalagoso.
